# Conventions de developpement

- Une PR de travail maximum, une fonctionnalite par changement.
- Changement minimal et tests de regression correspondants.
- Python 3.11 et standard library par defaut; dependances tierces soumises a verification explicite.
- Convention de nommage: snake_case pour Python, noms de fichiers lisibles, conventions web standards.
- Ne pas ajouter de nouveaux fichiers generes sans tests sur leur syntaxe et leur usage.
- La CI doit executer les memes commandes que la documentation.
- PR: objectifs, changements, tests et risque securite, limites.
